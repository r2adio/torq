* torq
A BitTorrent client implementation in TypeScript using Bun.

** Features
- *Decode* - Decode bencoded strings
- *Info* - Display torrent file metadata (tracker URL, length, info hash, piece info)
- *Peers* - Discover peers from tracker
- *Handshake* - Perform BitTorrent handshake with peers

** Installation
#+begin_src bash
bun install
#+end_src

** Usage
#+begin_src bash
# opens the terminal ui
bun dev

# display torrent file info
bun dev info sample.torrent

# discover peers from tracker
bun dev peers sample.torrent

# perform peer handshake with tracker
bun dev handshake sample.torrent <peer_ip>:<peer_port>

# downlaod a piece from tracker
bun dev downlaod_piece -o /tmp/test-piece sample.torrent <piece_index>
#+end_src

** Development
#+begin_src bash
# run cli
bun run dev:cli

# run tests
bun test
#+end_src

** Project Structure
- ~app/main.ts~ - Entry point
- ~app/cmds/~ - CLI commands
- ~app/core/~ - Core torrent logic
- ~app/utils/~ - Utilities (bencode, buffer)
- ~app/ui/~ - UI components (TUI)
