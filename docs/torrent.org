#+title: Torrent 

* Internal Structure of a Torrent File
** single-file torrent
   torrent
   └── info
     ├── name: "hello.txt"
     ├── piece length: 16384
     ├── length: 1234       <-- single file
     └── pieces: <binary hash>
** multi-file torrent
   torrent
   └── info
     ├── name: "my-folder"
     ├── piece length: 16384
     ├── pieces: <binary hash>
     └── files:
       ├── path: ["file1.txt"], length: 1000
       └── path: ["subfolder", "file2.txt"], length: 2000
